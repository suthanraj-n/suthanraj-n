## Selected work

### [EPICare — Clinic & Practice Management](https://helyxon.com/landing/epicare/)

A platform bringing appointments, registration, consultations, e-prescriptions, tele-consultation, payments, and medical records into one outpatient workflow. Native ABHA/ABDM integration supports interoperable health data exchange, with AI-enabled workflows designed to reduce administrative effort and consultation friction.

### [VITALL / iVital+ — Remote Patient Monitoring](https://helyxon.com/landing/saki/)

In 2016, a NICU workflow problem sparked a personal project: stream medical device readings outside sterile zones so clinicians could check live vitals without repeatedly entering them.

That project evolved into a cloud-based monitoring platform with live ICU/NICU vitals, multi-patient dashboards, alert escalation, video integration, and secure remote access. During COVID-19, it helped support centralized clinical supervision while reducing exposure and PPE usage.
